# Restaurant Menu & Billing System (C Language)

A simple, console-based billing and menu application written in C. It allows users to view a food menu, select items, adjust quantities, and generate an itemized bill with taxes directly in the terminal.

## Features

* **Interactive Menu:** Simple terminal interface for browsing available food and beverage items easily.
* **Order Customization:** Select multiple items and adjust quantities during order placement.
* **Automated Bill Generation:** Generates an itemized summary displaying selected items, subtotal, taxes, and final total cost.
* **Console Interface:** Light and fast terminal-based execution built with pure C.

## Included Files

* **`main.c`** — Source code containing menu structures, order selection logic, and bill printing routines.
